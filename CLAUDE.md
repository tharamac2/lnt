# Project Instructions

## Git workflow

This repo's remote is `https://github.com/tharamac2/lnt.git` (branch `main`).

After completing any code change (feature, fix, or style update), automatically:
1. `git add` the changed files and commit with a concise message describing the change.
2. `git pull origin main` (merge in any upstream changes).
3. `git push origin main`.

Do this without asking for confirmation each time, unless the pull produces merge
conflicts that need manual resolution — in that case, stop and ask the user.
